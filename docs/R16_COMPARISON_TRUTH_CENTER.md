- **方案 C 雲端 AI 分析與分析 SDK**：違反本機優先與無自動傳送承諾，拒絕。

## R16 B 實作契約
1. `src/view_filters.js` 無依賴純函式模組，提供五群比較條件、未確定四種狀態完整加總、保守三路決策、限額列表分頁，以及六種已知覆蓋風險篩選。只在記憶體內持有來源物件。
2. `src/app.js` 與 `index.html` 提供兩種篩選：比較結果（全部／差異／新增／新版未見／未確定／僅中繼資料）和對話風險（全部／標題截短／文字截短／目前分支不可用／其他分支／非文字）。同時保留原搜尋；切換、清除、重比對時清掉舊控制狀態。
3. 比較列表每頁80項，所有已解析結果可用上一頁／下一頁看到；不改 export summary，不新增任意內容可上傳欄位；「無法確定」包含四種 INCONCLUSIVE_*，不是完整備份認證。
4. `src/view_filters.js` 同時導入來源頁與 standalone builder，build SHA/CSP parity 必須 PASS。
5. 保留 R6 ZIP/JSON caps、R9 清除、R10 HTML 確認、R12 16MiB bytes cap、R13/14 truncate unknown 狀態、R15 對話列表200分頁。
6. 全程原創合成資料，無任何私人聊天匯出、外部真人樣本、OpenAI 計畫核准聲明。

## 禁止行為與負面情境
- 雙份匯出內容不同，不可將「新版未見」誤寫成刪除。
- 當未知狀態存在，不能宣稱二者一致或比對完整。
- 無對比結果時不可顯示上輪私人對話名稱、清空後不得留在 DOM。
- 篩選和搜尋必須同時生效；無結果的狀態仍需有固定空值提示。
- 有120筆以上差異可以逐頁讀取，不能默默隱藏。
- UI 控制必須能用鍵盤操作，手機不水平溢出，強 CSP 不移除。
- 封包 Manifest 與 release workflow 針對新版本同步；舊 tag 與 workflow 不覆寫。

## 風險
這是已知限制下的本機視覺化改進，不是帳戶完整性驗證、真人採用或安全審計。下一版是否需要更多互動，依可重現測試或後續獨立使用者證據決定。
