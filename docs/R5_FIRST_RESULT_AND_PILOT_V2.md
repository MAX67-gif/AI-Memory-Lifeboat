# R5｜第一份可閱讀結果與自願試用回饋 v2

**版本**：v0.5.0 Preview（2026-11-02）。**真人獨立試用**：`NOT_COLLECTED`。**官方來源完整性**：`NOT_VERIFIABLE_FROM_EXPORT`。

## 先完成一個對人有用的任務

1. 開啟 `index.html`，點選「試用合成示範」。它只包含專案原創假資料，不必提供個人匯出。
2. 在結果頂部依序使用三個導覽捷徑：健康指引、兩次匯出比較、閱讀一則對話。捷徑是一般錨點連結，**不記錄完成行為**，也不自動推論使用者理解程度。
3. 在「備份體檢」按「下載可閱讀的純文字摘要 TXT」；內容僅使用程式內固定字句、有限數值、來源類型及檢查狀態，**不複製**聊天內容、標題、ID、檔名或路徑。
4. 需要檢查自己的備份時，透過官方管道自行取得 ZIP 或 `conversations.json`，在本機載入；不要將來源 ZIP 提交至公開 Issue。
5. 自願者可以只在本機完成五題固定選項，下載 JSON 後**自行審閱並決定是否分享**。沒有上傳後端，也不會自動提交 GitHub。

## 純文字報告契約

`AMLFirstResult.format(aml.health.v1, source_mode)` 產生 `text/plain`，輸出模式只有 `SYNTHETIC_DEMO`／`PERSONAL_EXPORT`。所有標題、建議與局限性均來自可信白名單，不反射外部對話資料或未知健康檢查欄位。即使沒有問題也會明確顯示：**僅限已支援項目未見異常，不是帳戶完整性或平台可還原性保證**。

`SYNTHETIC_DEMO` 永遠醒目標示非真實帳戶；附件 CRC32 僅為 ZIP 內部一致性，不代表原始附件真實完整；差異結果無法確定帳戶刪除。

## 自願回饋契約 v2

- 新增 `aml.pilot-feedback.v2`，不取代仍可使用的 v1。v1 工具程式 `src/pilot.js` 保持不變；新的 v2 實作在 `src/pilot_r5.js`。
- 固定欄位 `ease`、`clarity`、`reuse`、`firstTask`、`understandsScope`；均僅接受白名單列舉，預設 `NOT_TESTED`，無自由輸入，額外欄位一律捨棄。
- `firstTask` 是使用者自述完成情況；`understandsScope` 是自我理解程度。**不會**推論實際完成率或變成經外部獨立驗證的試用證據。
- 不含聊天內容、標題、對話 ID、檔名、來源路徑、電子郵件、時間戳、裝置資訊、聊天雜湊等。絕不自動送出。GitHub Issue 有公開帳號識別性，非匿名服務。

## 待辦與反證

真人研究仍須取得明確同意，由測試者在自己裝置執行，若無法完成，保留真實失敗結果。使用者能完成合成示範≠本人匯出真的可讀。需與官方匯出閱讀流程及至少一款現成 Viewer 比較任務完成率、時間與誤解率。無可驗證的外部回饋，不宣稱 adoption。
