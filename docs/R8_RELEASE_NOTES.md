# AI Memory Lifeboat v0.8.0 — Offline First

- **Download** `AI_Memory_Lifeboat_Offline.html` and open it locally in a supported desktop browser. No account, API key, cloud processing or Node.js required.
- **Try before trusting:** select **Try synthetic demo / 試用合成示範**. This uses fictional data and is not a personal backup verification.
- **Check your own ChatGPT export** by selecting the official ZIP or JSON on your device. Existing R6 bounded numbered shards, conservative audits, snapshot diff and attachment CRC checks are unchanged.
- **Verify downloaded bytes** with `SHA256SUMS.txt`. The source ZIP is an exact archive of the release commit. Checksums demonstrate release-file consistency, *not* full ChatGPT account completeness or malware-free guarantees.
- **Limitations:** advanced UI remains primarily Traditional Chinese; unsupported ZIP64, encrypted archives, large files above existing caps, and other AI providers. Keep your original official export.
- **Evidence:** Release assets generated after `npm run check` on the release commit. No independent human adoption or hosted GitHub Pages claim.

Privacy: No hosted upload endpoint, no runtime network calls. The optional single-conversation HTML exports **do contain the selected chat text**, so treat them as private files.
