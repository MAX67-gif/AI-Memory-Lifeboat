# R25｜對話清單頁碼直達、選取租約與安全交付契約

## A：問題、基線與反例
- 原 R15 每頁最多 200 筆但只有上一頁／下一頁；R6 可解析最多 30,000 筆，即 150 頁。前往頁尾最多需要按 149 下，與 R19 的差異跳頁體驗不一致。
- 不增加列表可見筆數、不改搜尋範圍、不猜測任何新備份格式。R18 當所選對話離開本頁，必須清除私密 DOM／停用 HTML 原文下載並撤銷待確認視窗。
- 繼承 R19 既有嚴格 1-based `jumpToPage(value,totalPages)`，而不是引入易容錯或允許科學記號的解析器。

## B：正式修正界線
- 僅至少三頁顯示 `listJumpWrap`，最終跳頁先以當前 `searchConversations` + `riskFilter` 計算有效總頁數。
- 合法序號顯示實際頁數並更新該頁 200 筆；無效序號不更動頁碼、不重繪、不更改既有選取；不反射使用者輸入或私人名稱到錯誤報告。
- 有效跳頁由既有 `renderList` 以 `selectionOnCurrentPage` 正確檢查，同頁選取仍維持；跨頁選取撤銷原文下載、清除舊閱讀內容與待確認狀態。
- IME `isComposing`、229 必須被阻止；搜尋、風險篩選、來源切換、清除時跳頁欄位／錯誤旗標歸零。
- 活動僅在本機頁面；不得將跳頁資料寫入可分享的 JSON/TXT 健康報告。

## 測試矩陣
- Node：30,000/200=150 頁，上下界、越界、空白、負數、科學記號、先導零、分數、JS 非字串；HTML semantic/label/status；app 正反狀態轉移與舊 R18 guard。
- Chrome：使用純合成資料生成 421 筆（3頁），測合法第1/2/3頁與保留/撤銷選取、非法跳頁與 IME、搜尋篩選後回頁首、清除、同ID來源替換與私人匯出資格撤銷。desktop 1280×900 和模擬手機390×844 各自完整過一次。
- 發行：Node、Chrome、manifest、離線 HTML script/style CSP hash、單一 source ZIP CRC/SHA、Release tag immutable；R22 舊發布工作流程不修改。

**未驗證：**真實人類輸入法、螢幕閱讀器、實體手機、帳戶完整性；所有驗證以實際工作流程回執為準。
