# R10｜敏感單篇 HTML 匯出的本機確認契約

**產品目標：**讓一般使用者清楚區分「不含聊天原文的健康報告」與「含私人聊天內容的單篇閱讀 HTML」，避免誤按直接產生含原文檔案。

## 行為邊界

1. 先載入自己有權使用的 ChatGPT ZIP／JSON 或原創合成示範；只在明確選到一則可讀對話後開放 HTML 匯出。
2. 按「下載目前對話 HTML（含原文）」只開啟 HTML `<dialog>`，不產生 Blob、不下載檔案；對話框以鍵盤及螢幕閱讀器可辨識的標題與說明呈現。
3. 只有按「了解，下載含原文 HTML」才下載當前選定對話；按取消、Esc、關閉、清除、來源切換或選擇其他對話均撤銷未完成的確認。
4. 確認記錄只存在當前頁面的記憶體；本工具沒有網路收集、沒有持久紀錄、沒有帳戶認證、沒有自動匿名化。保留來源官方 ZIP。
5. 健康 JSON、純文字摘要、稽核與差異報告均維持直接本機下載，不複製對話文字、標題、ID 或附件路徑；單篇 HTML 明確標示其敏感性。

## 安全性與不可宣稱

確認僅降低誤操作，不是加密、刪除既有下載、不可能被分享的保證或完整備份認證。瀏覽器若不支援原生安全對話框，**拒絕含原文匯出**，不可降級成直接下載。前版 R9 的清除 DOM 與附件重驗撤銷結果維持不變。

## 合成測試與正式驗收

- RED：R9 直接下載沒有確認；新四題公開 DOM 情境應失敗。
- GREEN：確認後下載、取消不下載、來源切換/清除撤銷、Esc 撤銷、無原文稽核報告仍直接下載。
- 獨立 Node 全套＋Chromium 真實頁面兩種尺寸，核對無 CSP 違規、沒有上傳、沒有私人資料洩漏到 PUBLIC。
- Feature PR exact SHA CI PASS → 合併 main CI PASS → 一次性 R10 Release SHA/CRC 驗證 → 私人 AML-only 接續，不改 TLS。
- 真人完成/理解與 Codex for Open Source 採用證據：**NOT_COLLECTED**。不擬造通過率。
