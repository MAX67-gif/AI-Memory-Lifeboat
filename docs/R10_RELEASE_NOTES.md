# AI Memory Lifeboat v0.10.0 — Share-Safe Offline

- **Safer exports:** downloading single-conversation HTML containing chat text now requires an explicit local confirmation, with Cancel, Escape and source-switch revocation.
- **Unchanged privacy:** all data stays in the browser; no account, token, telemetry, server uploads or AI APIs. Content-free health and audit reports remain one click.
- **Unchanged parser:** ChatGPT ZIP/JSON shard limits, branch model, snapshot comparison and attachment CRC32 semantics remain as previously released.
- **Offline download:** `AI_Memory_Lifeboat_Offline.html` from this Release; `AI_Memory_Lifeboat_Source_v0.10.0.zip` is an exact archive of the released commit; `SHA256SUMS.txt` verifies these release bytes.
- **Limitations:** not a complete account backup, an attachment authenticity certificate, a secure deletion tool or a platform restoration. Downloaded single-chat HTML contains the selected conversation text and title. Advanced UI remains mostly Traditional Chinese.
- **Evidence:** synthetic Node/Chromium tests and GitHub Actions are engineering evidence only. No independent human adoption, third-party validation or Codex for Open Source acceptance is claimed.
