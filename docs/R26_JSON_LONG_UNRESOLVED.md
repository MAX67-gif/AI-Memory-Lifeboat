# R26 未完成反證：9 MiB 長文字對話選取後 CDP 無法回應（2026-11-24）

此文件保留未驗證事項，不屬於 v0.11.3 的發行通過條件。

在原 `v0.11.2` 與 R26 公開研究 PR #27 中，8.8 MiB / 240 則長文字合成 JSON 完成匯入與選取的第一個 DOM 檢查，但接下來原生 Chrome DevTools 指令（`Runtime.getHeapUsage`、後改 `Performance.getMetrics`）均出現 120 秒無回應，三次獨立 CI head 均有實際 RED。這可能涉及大量可見文字排版／主執行緒阻塞，**不能確認是純測量器缺陷，也不能宣稱這份來源實際使用時毫無卡頓**。

R27 CRC32 優化只針對 ZIP CRC 的可重現耗時，**不假稱解決此 JSON 長文字反例**。研究 PR #27 保留開啟且不可在失敗 CI 下合併；下一輪應先獨立測 `selection-to-CDP-response`、瀏覽器 long-task/CPU、不同 700-message 窗口數與每則文字長度，預先凍結測試矩陣，針對可重現產品瓶頸另提最小修正。

所有資料為原創虛構；不能當真實帳戶完整性、真機效能或 64MiB 上限證明。
