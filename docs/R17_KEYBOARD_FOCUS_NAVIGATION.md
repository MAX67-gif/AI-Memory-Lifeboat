# AI Memory Lifeboat R17｜鍵盤焦點連續性與有界導覽

日期：2026-11-15（臺灣時間）
基準：R16 v0.10.5 官方 GitHub 主線與已發行來源 ZIP。
狀態：工程候選；只有實際 PR／CI／Release 驗收後才可稱正式發布。

## A：觀測、反證與裁決

以相同 R16 原始單檔 HTML 在 Chromium 載入**原創合成備份**：聚焦對話清單第一個按鈕，按 Enter 觸發選取後，清單重新產生，`document.activeElement` 從原按鈕掉到 `BODY`。這是可重現的鍵盤可及性缺陷，不涉及匯出內容正確性。本輪不新增 AI 平台、雲端模型、ZIP64 或存取權限。

## B：明確行為契約

1. 使用清單中的按鈕（滑鼠或鍵盤）選取對話時，重新產生清單後把焦點留在**當次選取**的按鈕，不因 DOM 替換遺失；不以焦點變動自動開啟聊天或下載。
2. 上/下方向鍵依本頁可見清單索引移動焦點，Home/End 到本頁首尾；在首尾不會跨頁或繞圈。Enter/Space 才觸發選取。
3. 分頁、搜尋與風險篩選仍沿用 R15/R16 語意；切換資料或篩選後不偷偷還原舊選取或含原文下載資格。
4. 不將原文、標題、IDs、檔案名稱、搜尋字串或焦點位置傳送網路、寫入報告或持久儲存。
5. 保留 strict CSP、原生 `button`、`aria-current`、200 筆清單上限、R16 的 80 筆差異分頁及全部四種未知比較狀態。

## 覆蓋與限制

Node 單元測試驗證所有導航按鍵、空清單、非法索引、首尾夾限與非導覽按鍵；Chromium 以合成資料驗證選取後焦點實際保留及下一個可聚焦項目。測試不能取代真實使用者與輔助科技的驗收；真人驗證依維護者決定延後。`file://` 在沙盒因管理政策無法直接導航，僅驗證以同位元組 HTML 建立的隔離頁面。

## 回滾

舊版 v0.10.5 Release/tag 與 R16 工作流程保持不變。R17 不變更解析器、Schema、健康判讀、下載確認或儲存行為。若鍵盤修復造成新問題，應使用舊正式 Release，重新從失敗案例裁決，不應覆寫舊標籤。
